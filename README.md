# University research output indicators

Data and code for “Bibliographic corrections and university research output indicators: Institutional consequences and validation requirements.” The study examines 400 audited institution–work pairs and 2,000 additional pairs sampled from 50 US universities.

**[Run in Google Colab](https://colab.research.google.com/github/evidenceworks/university-portfolio-validity/blob/main/notebooks/reproduce.ipynb)**

Select **Runtime → Run all**. The notebook retrieves the public data, verifies 17 checksums, runs Quick and Core, and downloads `university_output_results.zip` with 19 numerical result files. No manual upload is required.

The estimated indicator change is 65,785 institutional credits (approximate 95% interval: 48,753–82,817); this does not establish publication eligibility. In the audited sample, establishing the university-level count comparison requires at least 41 additional eligible findings, including 32 on unchanged decisions.
